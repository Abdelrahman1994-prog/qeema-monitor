# Qeema Website Monitor

تطبيق مراقبة مجاني وكامل لموقع qeema.net، بيشتغل تلقائي على GitHub Actions
(من غير ما تحتاج سيرفر أو خدمة زي UptimeRobot)، وبيبعتلك إيميل فوري لو حصلت
أي مشكلة.

## اللي بيتم فحصه كل مرة

- **Uptime**: هل الموقع بيرد ولا لأ (status code) ووقت الاستجابة
- **SSL**: هل شهادة الأمان قربت تنتهي (تنبيه قبل 14 يوم)
- **لينكات مكسورة**: بيفحص كل اللينكات الداخلية في الصفحة (لحد 60 لينك)
- **تغييرات المحتوى**: بيقارن محتوى الصفحة بآخر فحص وينبهك لو اتغير
- **SEO أساسي**: title, meta description, H1, viewport
- **Security headers**: HSTS, X-Frame-Options, CSP, وغيرهم
- **انتهاء الدومين**: تنبيه قبل انتهاء تسجيل الدومين بـ 30 يوم (best-effort)
- **HTTP → HTTPS redirect**: هل النسخة الغير آمنة بتحول تلقائي للآمنة

كل حالة (آخر status, اللينكات المكسورة, الهاش بتاع المحتوى...) بتتحفظ في
`data/state.json` عشان النظام يعرف يفرق بين مشكلة جديدة ومشكلة معروفة من
قبل، ومش هيقولك على نفس المشكلة كل نص ساعة.

## خطوات التشغيل (مرة واحدة بس، حوالي 10 دقايق)

### 1) اعمل مستودع (repository) جديد على GitHub

- ادخل على github.com وسجل حساب لو معندكش
- اعمل "New repository" وسميه مثلاً `qeema-monitor`
- **الأفضل: خليه Public** — عشان GitHub Actions تبقى مجانية بلا حدود على
  المستودعات العامة. لو عايزه Private، حساب GitHub المجاني بيديك 2000
  دقيقة شهريًا، وده كافي مع فحص كل 30 دقيقة (شوف الحساب تحت).

### 2) ارفع الملفات دي على المستودع

كل الملفات اللي في هذا المجلد (`monitor.py`, `requirements.txt`,
`.github/workflows/monitor.yml`, `data/`) — ارفعها زي ما هي بنفس الأسماء
والمسارات، إما عن طريق:
- زرار "Add file → Upload files" في واجهة GitHub مباشرة، أو
- `git add . && git commit -m "initial commit" && git push` لو مرتاح مع git

### 3) جهّز إيميل الإرسال (Gmail App Password)

الإرسال بيتم عن طريق حساب Gmail (مجاني):

1. فعّل "2-Step Verification" على حساب الـ Gmail اللي هتبعت منه (لازم
   يكون مفعّل عشان تقدر تعمل App Password)
2. روح على: https://myaccount.google.com/apppasswords
3. اعمل App Password جديد (اختار "Mail" كنوع التطبيق)
4. هيديك كود من 16 حرف — احتفظ بيه، ده اللي هتحطه بدل الباسورد العادي

### 4) ضيف الـ Secrets في المستودع

روح على المستودع بتاعك → **Settings** → **Secrets and variables** →
**Actions** → **New repository secret**، وضيف كل واحد من دول:

| الاسم       | القيمة                                                |
|-------------|--------------------------------------------------------|
| `SMTP_HOST` | `smtp.gmail.com`                                        |
| `SMTP_PORT` | `587`                                                   |
| `SMTP_USER` | إيميل الـ Gmail اللي هتبعت منه                          |
| `SMTP_PASS` | الـ App Password اللي عملته في الخطوة اللي فاتت (16 حرف)|
| `ALERT_TO`  | الإيميل اللي عايز تستقبل عليه التنبيهات                |

اختياري: لو عايز تراقب رابط مختلف عن `https://qeema.net/home`، روح على نفس
الصفحة بس اختار تبويب **Variables** بدل **Secrets** واعمل variable اسمه
`SITE_URL` بالرابط اللي عايزه.

### 5) شغّله

- روح على تبويب **Actions** في المستودع
- لو ظهرت رسالة تفعيل الـ workflows، اضغط "I understand my workflows, go
  ahead and enable them"
- اختار "Qeema Website Monitor" من القايمة على الشمال، واضغط "Run workflow"
  عشان تجربه فورًا بدل ما تستنى نص ساعة
- لو كل حاجة تمام مش هتوصلك أي إيميل (ده متعمد عشان ميبقاش إزعاج) — هتلاقي
  رسالة "كل حاجة تمام" في لوج الـ run نفسه. لو فيه مشكلة، هيوصلك إيميل فورًا

## ملاحظات مهمة

- **التكرار الافتراضي كل 30 دقيقة.** لو عايزه كل 15 دقيقة وحابب تخليه على
  Private repo، احسب: 96 مرة/يوم × ~دقيقة للتشغيل ≈ 2880 دقيقة/شهر وده
  أكتر من الـ 2000 المجانية. لو المستودع Public مفيش مشكلة خالص، غير
  السطر `cron: "*/30 * * * *"` في `.github/workflows/monitor.yml` إلى
  `"*/15 * * * *"`.
- **GitHub بيوقف الجدولة (schedule) تلقائيًا لو المستودع فضل من غير أي
  نشاط (commit) لمدة 60 يوم.** هيبعتلك إيميل تحذير قبلها. لو حصل، بس
  ادخل واعمل "Run workflow" يدوي أو أي commit بسيط وهيرجع يشتغل عادي.
- التنبيهات على المشاكل "المستمرة" (زي SSL هينتهي) بتتبعت مرة واحدة بس
  مش كل نص ساعة، وفيه "ملخص يومي" منفصل لمشاكل الـ SEO والـ security
  headers عشان ميبقاش فيه إغراق إيميلات.
- تقدر تتابع تاريخ كل الفحوصات (uptime %, أوقات الاستجابة) من ملف
  `data/history.csv` اللي بيتحدث تلقائي في المستودع.
